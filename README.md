## 📖 Sobre o projeto

O **House Painting** é um exercício do FreeCodeCamp criado para praticar a construção de elementos visuais utilizando HTML e CSS.

A paisagem é composta por diferentes elementos HTML, incluindo uma casa, chaminé, telhado, janelas, porta, sol, céu, montanha, estrada, grama e nuvens.

Cada elemento é criado individualmente no HTML e estilizado através do CSS.

O projeto não depende de imagens para construir a cena: os elementos visuais são formados utilizando propriedades do CSS, como dimensões, posicionamento, bordas, cores e `border-radius`.

A casa, por exemplo, utiliza `position: relative`, dimensões definidas, bordas e uma cor de fundo para formar sua estrutura.

## 📚 O que aprendi

Este desafio foi importante para praticar conceitos fundamentais de **CSS e posicionamento de elementos**.

### 🎯 Posicionamento

Aprendi a utilizar:

```css
position: relative;
position: absolute;
```

Isso permitiu posicionar elementos individuais em relação à cena e à casa.

### 📐 Dimensões

Pratiquei o controle de tamanho utilizando:

```css
width
height
```

### 📍 Controle de posição

Também pratiquei:

```css
top
bottom
left
right
```

Essas propriedades foram utilizadas para determinar a localização dos elementos na composição.

### 🧩 Camadas

Utilizei:

```css
z-index
```

para controlar a ordem em que determinados elementos aparecem na cena.

### 🎨 Construção de formas com CSS

O projeto mostrou que é possível criar formas simples sem imagens externas, utilizando propriedades como:

```css
border
border-radius
background-color
```
